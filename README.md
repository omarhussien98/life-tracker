# All-in-One Life Tracker

A personal web application built with **HTML, CSS, JavaScript, TailwindCSS, and Chart.js**.  
This project provides multiple trackers in a single dashboard to manage daily life activities.

##  Features
- **Dashboard:** Overview of habits, goals, finance, health, journal, and events.  
- **Habit Tracker:** Add, complete, and monitor daily habits with streaks.  
- **Goal Tracker:** Create goals with progress tracking.  
- **Finance Tracker:** Record income & expenses with real-time balance chart.  
- **Health Tracker:** Log weight, workouts, and mood with chart visualization.  
- **Journal:** Save daily thoughts and reflections.  
- **Calendar:** Add and view upcoming events.  
- **Dark Mode:** Toggle between light and dark themes.  
- **Local Storage:** Data persistence without a database.

##  Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- TailwindCSS for styling
- FontAwesome for icons
- Chart.js for data visualization
- LocalStorage for offline persistence
